**NCapture**
------------

You may want to import in content from the web, and NVivo can help with this. To do so, you need to install a plugin for Google Chrome. Most web pages can be captured as PDFs. You can also capture some pages from Facebook, X (Twitter), and YouTube as datasets, videos and pictures. NCapture files (.nvcx) contain your captured content as well as the URLs, capture times and any additional information such as a description, memo and coding that you specified at the time of capture. To use NCapture, you would use Chrome to go to the page you want to capture, and then click on the NCapture button to capture the content. These NCapture files can then be brought into NVivo to analyze. However, I will warn you that it is fairly limited in its use and the results can be unpredictable – it’s really best for capturing web pages. For extensive social media data gathering, other tools are better suited than NVivo to capture them.

For this tutorial, let's capture an article for analysis in NVivo.

1. First we need to install NCapture in Chrome. Go to [NCapture for Chrome](https://chrome.google.com/webstore/detail/ncapture/lgomjifbpjfhpodjhihemafahhmegbek) in the Chrome Web Store.

    <img src="{{ '/assets/images/NCapture_1.png' | relative_url }}" alt='NCapture page on the Chrome web store. ' title='' width='100%' height='100%' />

  
 

2. Click the Add to Chrome button.

    <img src="{{ '/assets/images/NCapture_2.png' | relative_url }}" alt='NCapture Chrome web store page with Add to Chrome highlighted.' title='' width='100%' height='100%' />

  
 

    Then click on Add extension to confirm.

    <img src="{{ '/assets/images/NCapture_3.png' | relative_url }}" alt='Add NCapture dialogue box with Add extension highlighted. ' title='' width='458' height='235' />

  
 

    NCapture for Chrome is added to Chrome, with an icon in the toolbar. If you don’t see it, click on the puzzle piece to display all your extensions, and then click on the pin icon to pin NCapture to your extensions bar.

    <img src="{{ '/assets/images/NCapture_4.png' | relative_url }}" alt='Chrome extensions menu with the pin icon for NCapture highlighted.' title='' width='452' height='286' />

  
 

3. Next, let’s try a really simple example of capturing a webpage as a PDF file. Use Chrome and go to this URL: [https://www.theglobeandmail.com/business/industry\-news/property\-report/article\-demand\-for\-storage\-space\-in\-the\-cloud\-creates\-a\-land\-rush/](https://www.theglobeandmail.com/business/industry-news/property-report/article-demand-for-storage-space-in-the-cloud-creates-a-land-rush/)

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_003.png' | relative_url }}" alt='The Globe and Mail web article titled "Demand for storage space in the cloud creates a land rush"' title='' width='1070' height='609' />

  
 

4. Click on the NCapture icon on the top right of Chrome (you will need to accept an end\-user license agreement the first time you use it).

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_004.png' | relative_url }}" alt='NCapture extension menu with Accept highlighted. ' title='' width='100%' height='100%' />

  
 

5. When you click on the NCapture icon, you are presented with the choice of capturing the entire page, including headers, ads, etc. or just the main article itself as a PDF. Let’s choose the article – so select Article as PDF.

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_005.png' | relative_url }}" alt='NCapture extension menu with Article to PDF highlighted. ' title='' width='443' height='513' />

  
 

6. You will see it shows you a simplified version of the page and what it will capture.

    <img src="{{ '/assets/images/NCapture_6.png' | relative_url }}" alt='The Globe and Mail web article simplified to just article content. ' title='' width='1152' height='976' />

  
 

7. You can give it a name if you like, but let’s keep the default name in this case.

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_007.png' | relative_url }}" alt='NCapture extension menu with the Name field highlighted. ' title='' width='443' height='513' />

  
 

8. We could provide a description and/or attach a memo if you like. We can skip that for now.

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_008.png' | relative_url }}" alt='NCapture extension menu with the Description field highlighted. ' title='' width='443' height='513' />

  
 

9. You can also code the entire thing with a code, if appropriate. Let’s leave it blank.

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_009.png' | relative_url }}" alt='NCapture extension menu with the Code at Nodes field highlighted. ' title='' width='443' height='513' />

  
 

10. Finally click on the Capture button.

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_010.1.png' | relative_url }}" alt='NCapture extension menu with Capture highlighted. ' title='' width='443' height='513' />

  
 

    You will see a small window pops up on the bottom right corner. Click on the link to see a full progress page in Chrome, because the pop\-up window will disappear after a short while, even if the capture has not finished (if you don’t see a pop\-up, you can click on the NCapture icon again to find a link to the progress page).

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_010.2.png' | relative_url }}" alt='NCapture notification with "Show capture progress page" highlighted. ' title='' width='437' height='245' />

  
 

    The progress page will allow you to stop the capture, if you made a mistake or it is taking too long.

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_010.3.png' | relative_url }}" alt='NCapture progress page.' title='' width='963' height='214' />

  
 

11. It should capture the page fairly quickly and another small window pops up on the bottom right corner that will notify you when the capture is complete. A pop\-up window may ask you where to save the file. Save it somewhere you can find it, such as your Desktop. If you are not prompted about where to save the file, check your Downloads directory, as that is often the default location where items will be saved.

    <img src="{{ '/assets/images/NVivo_Import_Data_Win_A_011.png' | relative_url }}" alt='NCapture notification indicating NCapture success. ' title='' width='405' height='232' />

  
 

12. Then go back to NVivo. Create a new project file or open up an existing project file that you want to import this into. From the left menu, under Import, select NCapture.

    <img src="{{ '/assets/images/NVivo_NCapture_Windows_0001.png' | relative_url }}" alt='NVivo with the import ribbon open and the NCapture option highlighted. ' title='' width='1206' height='210' />

  
 

13. Browse to the folder where the capture was saved.

    <img src="{{ '/assets/images/NVivo_NCapture_Windows_0002.png' | relative_url }}" alt='Import from NCapture wizard with Import From highlighted.' title='' width='917' height='610' />

  
 

14. You should now see the file in the list. Finally, click on Import.

    <img src="{{ '/assets/images/NVivo_NCapture_Windows_0003.png' | relative_url }}" alt='Import from NCapture wizard with the NCapture web article download checked off and highlighted. The Import button highlighted.' title='' width='917' height='607' />

  
 

15. NVivo will import the PDF file into your Files folder, but you can then move it to reorganize your files, if you wish.

    <img src="{{ '/assets/images/NVivo_NCapture_Windows_0004.png' | relative_url }}" alt='The web article NCapture as a PDF in the NVivo files folder.' title='' width='1508' height='526' />

  
 

16. If you double click on it, it will open up the PDF, and you will be able to read it and code the text. You may need to use the Zoom options on the bottom right to make the text larger to read.

    <img src="{{ '/assets/images/NCapture_16.png' | relative_url }}" alt='The web article NCapture opened in NVivo.' title='' width='1390' height='714' />
